# NLP API Contract

## Endpoint

POST `/classify`

## Request

```json
{
  "text": "maingay ang kapitbahay tuwing gabi"
}

Response
{
  "category": "Noise Complaint",
  "confidence": 0.87
}

Error Response
{
  "error": "empty_text"
}


This becomes the **shared agreement between Laravel and Python**.

When Sprint 3 arrives, Henry doesn't have to guess what your Python service returns, and you don't have to guess what Laravel expects.
